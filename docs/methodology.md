# 收录与复核规则

## 评估内容行为，不鉴定人格或作者身份

候选需有持续批量重复、误导营销、虚假体验等可具体解释的公开问题。仅仅用了 AI、内容写得工整、正常做营销、观点不同，均不足以收录。AI 检测分数不作为确定结论。

## 每个正式条目必须具备

- 从公开主页核实的固定 UID、干净的官方主页链接；昵称和小红书号为辅助信息。
- 至少两条不同的公开笔记链接、各自观察日期和具体说明；不能只写“像 AI”。
- 问题类型、事实观察、适用范围和限制，包含相反证据及替代解释检查。
- 人工复核人、复核日期、可追溯的候选 Issue。
- 已检查纠错、移出记录；公开前处理未解决的身份争议。

不保存带登录令牌的链接。公开证据优先使用 `https://www.xiaohongshu.com/explore/笔记ID` 等干净链接；缺少签名导致打不开时，标明不可独立复核并暂不收录，不以私有会话代替公开证据。不在仓库复制完整原文或未经许可的图片。

## 流程

线索 Issue → 核实 UID → 核查近期多个公开内容与反证 → 人工复核 → PR 检查 → 合并到正式名单并同步 UID 文件。

未复核线索留在 Issues，不进可执行文件。维护者不因收到报送就代表认可指控。报送者不得以名单用于骚扰、报复或组织举报。

## 更新与纠错

- 条目至少每 30 天复核一次；没有复核的条目不应继续作为当前执行依据。
- 任何人可用纠错 Issue 指出错认、证据失效、情况改变或请求移出，不需要提交身份证明等敏感资料。
- 有可信身份冲突或未解决的纠错时，先从可执行名单暂停该条目，记录原因，再核查。
- 移出时记录 UID、日期、原因、关联 Issue，不自动改变个人平台黑名单。
- 不承诺无法做到的响应时限；更新必须可追溯。
