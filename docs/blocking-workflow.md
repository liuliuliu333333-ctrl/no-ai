# 小红书官方拉黑步骤

验证日期：2026-11-24。环境：Mac 的 iPhone 镜像＋iPhone 小红书官方 App。操作执行后，官方主页明确出现“解除拉黑”和“你已经拉黑对方，无法查看TA的内容”。

## 首次连接

1. 打开 iPhone 镜像，用户本人完成手机解锁、首次允许和 Mac 验证。
2. 如果提示“iPhone 使用中”，用户锁定手机后再连接。
3. 本次选择“每次均询问”，没有开启自动认证；通知转发不是必要步骤。
4. 认证、解锁失败时暂停，让用户完成验证，不索取密码。

## 定位账号

1. 打开小红书 App。Mac 的镜像窗口可用 ⌘1 回主屏、⌘3 打开 Spotlight，搜索 `xiaohongshu` 后打开 App。
2. 点小红书右上角搜索，输入目标小红书号，切换“用户”。
3. 进入目标主页，核对小红书号、昵称、主页身份以及此前核实的固定 UID。小红书号可能改动，不应单独视为永久身份。
4. 如果身份不符、找不到对应账号或无法核实，停止该项，不凭近似搜索结果继续。

## 真正拉黑

1. 点目标主页右上角“…”（本次进入的是带“分享至”的底部菜单）。
2. 菜单底部有“复制链接、不看他、不让他看、举报、拉黑”；选择“拉黑”。
3. 出现“将『目标昵称』拉黑”确认框，核对目标后点红色“拉黑”。
4. 等待结果：主页按钮变为“解除拉黑”，并显示“你已经拉黑对方，无法查看TA的内容”。出现该状态才记为成功。
5. 保留用户本地执行记录。不要为了再次验证而解除拉黑。

## 本次踩过的坑

- 当前实测网页主页的更多菜单只有“举报”，消息页也未找到可见拉黑入口，因此转用 App；这不代表所有版本的网页永久没有该功能。
- 手机画面动画结束前输入可能丢字，应先观察稳定画面。
- 本次镜像粘贴未可靠传入新文本；数字账号用直接输入完成，并在搜索前核对整串数字。
- 镜像中的 App 无完整可访问性文字时，需用截图判断按钮。坐标随设备、窗口和版本变化，不应照抄固定坐标。
- 每次点击后读取新画面；不能把按钮点击成功当成平台操作成功。

这是一条单账号实测路径，不代表批量任务、所有设备或所有 Agent 均可使用。
